# League Rules
League Rules is the rules that the tsm players should follow so they can play their matches without violating the rules and also knowing how tsm works

## 1. Pitch:
- 1.0.0: The Match Must be **4v4, 4v3, 3v3** and not **4v2, 3v2, 2v2**
  - note: if the match started as 4v2 then its fft win to the team with 4 players, if 3v2 the same thing fft win for the team with 3 players, but if it was 2v2 then fft draw for the both teams
- 1.0.1: The Match Must start with a referee, without the referee the match won't start and won't played and the manager or the player of the team that gonna play the match is not allowed to ref his own game
  - note: the manager or the player can ref his own game only if the opponent team accepted and there is no active referees
- 1.0.2: The Private Server Hoster has to join the private server first and then sends the link of the private server in the matchcall allowing the players who is in lineups of both teams to enter
  - (note: if the hoster was north american and the host should be european or anything else then the private server owner has to send the private server to the player who is european via dms and not in the matchcall)
- 1.0.3: Penalty Shootouts and Sudden Death does NOT count even if the match was a cup
- 1.0.4: To Decide the Hoster, Both Teams has to choose between **Heads or Tails** and the winner is gonna choose the region host in which leg (the coinflip winner can not do double eu by himself without the opponent approval)
- 1.0.5: The Number of players on the private server should be **__7/10, 8/10, 9/10, 10/10__** and not **__1/10, 2/10, 3/10, 4/10, 5/10, 6/10__** and the players that should be in the private server are:
  - Referee (REQUIRED 1/1)
  - Streamer (OPTIONAL 1/1)
  - Team 1 (REQUIRED ?/4)
  - Team 2 (REQUIRED ?/4)
